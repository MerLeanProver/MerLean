# Support

Use the public GitHub issue tracker for installation problems, bug reports, and
feature requests:

<https://github.com/MerLeanProver/MerLean/issues>

Before opening an issue, remove API keys, credentials, private source code,
private proof plans, absolute home-directory paths, and other personal or
confidential information. Include the MerLean version, operating system, Codex
or Claude Code version, and the smallest non-sensitive reproduction.

For a suspected security vulnerability, use GitHub's private vulnerability
reporting interface when it is available instead of a public issue:

<https://github.com/MerLeanProver/MerLean/security/advisories/new>
