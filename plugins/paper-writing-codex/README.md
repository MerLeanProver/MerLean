# paper-writing-codex

Compose, refine, resume, and audit mathematics papers without losing results.

Entrypoint: `skills/paper-writing/SKILL.md`. Provider: `codex`.
Generated from the shared MerLean source; edit that source, not this bundle.
Setup: `bash scripts/setup.sh --project <Lean-project>`. For read-only plugin caches use `--runtime <writable-directory>` and the same `MERLEAN_RUNTIME` on later calls.
Offline graph: `PLAN_OFFLINE=1 scripts/merlean --data <data> status`. Paper operations: `scripts/paperctl --help`. Grades are evidence-based, not mode labels.
