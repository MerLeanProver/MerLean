# Route B ledger — `A² = A ⟹ tr A = rank A` over ℝ

**Representation:** factor `A` through `ℝ^r` with `r = rank A` installed as the inner dimension
(`A = BC`, `B : ℝ^r → ℝ^n`, `C : ℝ^n → ℝ^r`). The point of the representation: idempotence forces
`CB = I_r` exactly, so the trace is computed on the *small* side where it is a bare count of `1`s.

**Dependency use map (audit aid, not a proof step):**
- `A² = A` is consumed in **exactly one row: S9**. Every other row is generic linear algebra.
- `B` full column rank is consumed in **S6** (cancellation — the general lemma S5 applied to the `B` of S3) and **S8** (dimension equality).
- `C` full row rank is consumed **nowhere** (see S4).
- characteristic 0 — and, for clause (d), the ordered-field structure of ℝ — is consumed in **exactly one row: S17** (flagged *char-0 / ordered-field hinge*).

S0 | **Conventions, fixed for the whole ledger.** `n` denotes an integer with `n ≥ 0`. `M_{p×q}(ℝ)` is the set of `p×q` matrices with real entries, `M_n(ℝ) := M_{n×n}(ℝ)`. Two assertions of the row carry mathematical content and are proved here. **(i) Column-span identity.** Entrywise, for `i ∈ {1,…,p}`, `(Mx)_i = Σ_{j=1}^{q} M_{ij} x_j = Σ_{j=1}^{q} x_j (M e_j)_i`, since `(M e_j)_i = M_{ij}`; as this holds for every `i`, `Mx = Σ_j x_j (M e_j)`. Combining, `rank M ≤ min(p,q)`; and `rank M ≥ 0` since a dimension is a nonnegative integer. Both (i) and (ii) are used by later rows (S1, S3, S4, S5, S18).

S3 | **Rank factorization.** There exist matrices `B ∈ M_{n×r}(ℝ)` and `C ∈ M_{r×n}(ℝ)` such that `A = BC` and `rank B = r`. S5 | **A matrix of full column rank has trivial kernel.** The statement is the general one: for all integers `n, r ≥ 0` and every `B ∈ M_{n×r}(ℝ)` with `rank B = r`, the only vector `v ∈ ℝ^r` with `Bv = 0` is `v = 0`.
